# UART 仍无应答 — 二次修复（2026-09-18）

## 变更

1. `uart_send.v`：改为 **req/ack**（`send_en` 电平请求，完成后 `tx_done` 保持到 `send_en` 拉低），消灭上升沿漏采。
2. `uart_commend.v`：匹配 req/ack；上电/复位后主动发送 **`GuangOK\r\n`**。
3. 上位机连接后提示按复位，并尝试读取 banner。

## 烧录后请这样查

1. Vivado：**综合 → 实现 → Generate Bitstream → Program Device**（确认 bit 时间是新的）。
2. 打开串口助手或本上位机，**115200 8N1**。
3. **按板子复位键**，应立刻看到：`GuangOK`
4. 再发：`SINE:11258999\r`（约 1kHz PINC），应回 `Command Success!`

### 结果对照

| 现象 | 含义 |
|------|------|
| 复位后有 `GuangOK`，发指令也有 Success | 已恢复 |
| 有 `GuangOK`，发指令仍无应答 | TX 正常，查 RX 引脚(M17) / 线序 |
| 复位后仍无任何字符 | 未跑新逻辑：bit 未烧进、时钟/复位、或 TX 引脚(L17) |

波特率、线序、是否 Program 成功，优先用「复位横幅」一锤定音。
