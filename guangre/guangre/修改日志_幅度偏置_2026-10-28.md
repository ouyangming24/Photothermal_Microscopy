# 修改日志：幅度 / 偏置设置方式重做（2026-10-28）

## 问题

原 `sin_amp_offset.v` 的计算是：

```
code = sine * AMPL / 100 - bias + 510      // bias 为无符号 0~1023
```

偏置是**无符号数且被减掉**，所以只能把波形往下拉，无法上移；
另外中心是 510（不是 DAC 中点 512），AMPL 最小只能到 1。

## 新的定义

```
code = clamp( 512 + round(sine * AMPL / 100) + OFFSET , 0, 1023 )
```

| 参数 | 指令 | 范围 | 含义 |
|---|---|---|---|
| 幅度 | `AMPL:` / `AMPL_LIGHT:` | 0 ~ 100 | DAC 满幅的百分比；100 = 0~1023 满摆幅，0 = 只输出直流 |
| 偏置 | `OFFST:`（或 `OFFSET:`）/ `OFFSET_LIGHT:` | -1023 ~ +1023 | 有符号 DAC 码；0 = 中心在 512，**正数上移，负数下移** |

- 幅度 + 偏置超出 0~1023 时饱和（削顶/削底），不会回绕跳变。
- 复位默认：AMPL = 10，OFFSET = 0（波形以 512 为中心）。

示例：

```
AMPL:50\r\n          -> 半幅
OFFST:200\r\n        -> 上移 200 码
OFFST:-200\r\n       -> 下移 200 码
OFFSET_LIGHT:0\r\n   -> 光源通道回到中点
```

## 与旧版本的差异（注意兼容）

- 旧的 `OFFST:100`（下移 100）现在要写成 `OFFST:-100`。
- 旧的中心是 510，新中心是 512，同样的参数下电平会差 2 个码。
- 上位机 GuangHost 需使用 **v1.3.0** 及以上（偏置允许负数、幅度允许 0）。

## 如果板子上方向是反的

如果 AD9708 后面的模拟电路是反相的（示波器上看到 `OFFST:+200` 反而往下走），
把 `guang.v` 中的

```verilog
localparam DAC_INVERT = 0;
```

改成 `1` 即可，两路同时生效，不需要改上位机。
