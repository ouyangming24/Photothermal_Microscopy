# 相位可调补充说明（2026-09-17）

在 `修改日志_2026-09-17.md` 基础上新增 **相位可编程**。

## 变更摘要

1. **DDS IP**：`Phase_offset` 由 `Fixed` 改为 `Programmable`  
   - `dds_compiler_0.xci` / `dds_compiler_1.xci`  
   - CONFIG 总线变为 **96-bit**：`{POFF[47:0], PINC[47:0]}`（PG141）

2. **固件**  
   - 新指令：`PHASE:<POFF>`、`PHASE_LIGHT:<POFF>`（48-bit 相位字）  
   - `guang.v` 将 `{sine_phase, sine_freq}` 送入 DDS config

3. **上位机**（v1.2.0）  
   - 通道增加「相位(deg)」单独下发  
   - 自动换算：`POFF = deg/360 * 2^48`

## Vivado 必做步骤

打开工程后执行（或 Tcl Console）：

```tcl
source {<工程>/scripts/regenerate_dds_phase.tcl}
```

然后 **Reset / 重新综合实现**，再生成 bitstream。  
若综合报 `s_axis_config_tdata` 位宽不匹配，说明 IP 未重新 generate，请先跑上面脚本。

## 协议

```
PHASE:<POFF>\r
PHASE_LIGHT:<POFF>\r
```

- `POFF = 0` → 0°  
- `POFF = 2^48/4` → 90°  
- `POFF = 2^48/2` → 180°  

上位机填角度即可，例如 `90` 度。

## 验证建议

1. 两路同频：`SINE` 与 `SINE_LIGHT` 相同频率  
2. `PHASE:0`，`PHASE_LIGHT` 设 90°  
3. 示波器双通道应看到约 90° 相位差
