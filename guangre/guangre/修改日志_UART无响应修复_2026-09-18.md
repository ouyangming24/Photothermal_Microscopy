# Guang 工程修改日志：UART 无响应 / 频率不变（2026-09-18）

## 现象

新 bitstream 烧录后：串口发指令无 `Command Success!` 回包，DDS 频率也不随 `SINE` 变化。

## 根因

1. **DDS 位宽不匹配（综合已报警）**  
   - 顶层按相位可调改成了 96-bit `{POFF,PINC}`  
   - 但 `dds_compiler_0/1` **未成功 regenerate**，实际仍是 **48-bit 仅 PINC**（`C_PHASE_OFFSET=Fixed`）  
   - 综合日志：`width (96) does not match port width (48)`  
   - 频率通路不可靠

2. **UART 应答握手偏脆**  
   - `send_en` 长时间拉高 + 仅上升沿启动  
   - `tx_done` 仅 1 拍脉冲；若漏采会卡在 `WAIT_SEND`，之后所有指令都无响应、无回包

## 本次修复

| 文件 | 变更 |
|------|------|
| `uart_send.v` | 增加 `busy` 输出 |
| `uart_commend.v` | `send_en` 改为 **1 拍脉冲**；`tx_done` 粘滞采样；发送超时回 IDLE；`fsm_encoding=none`；应答字节改用 function |
| `guang.v` | 接 `tx_busy`；DDS config 改回 **48-bit PINC**；PINC/POFF 先同步到 `clk_dac` |

## 你需要做的

1. Vivado：**Reset Synthesis → Run Implementation → Generate Bitstream** 并重新烧录  
2. 用串口助手或上位机发：`SINE:<PINC>\r`，应立刻看到 `Command Success!`  
3. 示波器看 DAC 频率应变化
