Guang Host 上位机使用说明
========================

可执行文件
  dist\GuangHost.exe
  复制到其他 Windows 电脑即可运行，无需安装 Python。

目标电脑要求
  1. Windows 10/11 64位
  2. 已安装 USB-串口驱动（CH340 / CP210x / FTDI 等，视板卡而定）
  3. FPGA 已烧录 guang 工程比特流，UART 已接到电脑

操作步骤
  1. 用 USB 连接 FPGA 串口
  2. 双击 GuangHost.exe
  3. 选择 COM 口 → 连接
  4. 设置触发频率/占空比、两路正弦频率/幅度/偏置
  5. 点击「下发」或「一键下发全部参数」
  6. 日志中应看到 Command Success!

参数说明
  - 正弦频率：界面填 Hz，软件自动换算为 DDS PINC
  - 触发频率：界面填 Hz，下发为 Hz×1000
  - 占空比：界面填 %，下发为 %×1000（50% → 50000）
  - 幅度：0~100，单位 %（100 = DAC 满幅 0~1023，0 = 只输出直流）
  - 偏置：-1023~+1023，单位 DAC 码（满量程 1023）
          0 = 波形中心在 DAC 中点 512；正数上移，负数下移
          幅度 + 偏置超出 DAC 范围时波形会被削顶/削底
  注意：需配合 2026-10-28 之后的 FPGA 比特流；旧比特流的偏置
        是“只能下移”的无符号值，与本版本不兼容。

开发机源码运行
  pip install -r requirements.txt
  python app.py

重新打包
  双击 build.bat
